# forio-skills — навыки Claude Code для учёбы и дизайна

Маркетплейс плагинов для [Claude Code](https://code.claude.com). Навыки
русскоязычные: наставник, который не решает за тебя, уроки по новой теме с
записью в заметку, журнал мест, где ты застрял, тренажёр отладки сломанного
сервиса и дизайн интерфейсов в трёх вариантах.

| Плагин | Команды | Что делает |
|---|---|---|
| [`tutor`](#tutor) | `/tutor:tutor` | Наставник: задача уровнями подсказок без готового решения или урок по теме с тестами и записью в заметку |
| [`learned`](#learned) | `/learned:learned`, `/learned:recall` | Журнал остановок в Obsidian и разогрев по ним в начале следующей сессии. Пара к `tutor` |
| [`incident`](#incident) | `/incident:incident` | Тренажёр отладки: сервис упал в проде, найди причину за ограниченное число проверок — настоящий код, скрытые тесты, запечатанный ответ |
| [`web-design`](#web-design) | — | На визуальную задачу собирает три заметно разных варианта дизайна для живого сравнения |

## Быстрый старт

В Claude Code:

```text
/plugin marketplace add Forio224/claude-skills
/plugin install tutor@forio-skills
/plugin install learned@forio-skills
/plugin install incident@forio-skills
```

Перезапусти Claude Code и попробуй:

```text
/tutor:tutor тема: декораторы в Python
```

Наставник один раз спросит, куда записывать уроки (или учиться без записи), выяснит,
что ты уже знаешь, покажет план с картой темы и дождётся твоего «ок».

**Требования.** Запись урока в заметку делают хуки на Node.js 20+ — проверь
`node --version`. Без Node навыки работают, но урок останется только в чате.
Obsidian не обязателен: заметки — обычные `.md`, схемы mermaid и формулы
показывают и VS Code, и GitHub. Для `learned` нужен Obsidian с плагином
Dataview — на нём построена карта пробелов.

### Короткие команды без приставки

Claude Code всегда добавляет к командам плагина приставку (`/tutor:tutor`).
Чтобы вызывать `/tutor`, `/learned`, `/recall`, `/incident`, скопируй команды в личные:

```bash
# из клона репозитория — bash, macOS, Linux, Git Bash
cp plugins/*/commands/*.md ~/.claude/commands/
```

```powershell
# PowerShell
Copy-Item plugins\*\commands\*.md "$HOME\.claude\commands\"
```

После обновления плагинов команды копируются заново.

## Обновление

```bash
claude plugin marketplace update forio-skills
claude plugin update tutor@forio-skills
claude plugin update learned@forio-skills
claude plugin update incident@forio-skills
```

и перезапуск Claude Code.

## tutor

Два режима, выбираются по запросу.

**Задача** — LeetCode, учебный проект, ошибка в коде. Срабатывает на «объясни»,
«почему ошибка», «проверь мой код», «не давай решение».

- **Решение за тебя не пишется**, пока ты сам не поднимешь уровень помощи:
  1 — куда смотреть, 2 — какой приём, 3 — полный разбор. «Покажи решение» —
  сразу третий, без уговоров.
- **Ошибки называются все сразу**, включая скрытые и логические, — с причиной и
  порядком починки.
- **Проверка готового кода** — таблица краевых случаев, прямой вердикт, места
  «правильно случайно».

**Тема** — `/tutor:tutor тема: …`, «научи», «хочу разобраться в».

- **Разведка → план → урок.** Наставник ищет границу твоих знаний (тест всегда
  с вариантом «не знаю»), показывает план и карту зависимостей, ждёт «ок», затем
  идёт по узлам: зачем → утверждение → связь → проверка на свежем примере.
- **Тесты с конкретными данными**, варианты построены из реальных заблуждений.
  Неверный ответ разбирается показом: правильный ответ прогоняется на данных,
  твой — на примере, где он ломается.
- **Цель доказывается делом:** «писать X» — код с нуля, «узнавать X» — смешанный
  набор задач.
- **Запись урока.** Хуки дописывают весь урок в заметку с `тип: урок`, а по
  итогу ставят в начало сводку с картой и дату следующего повтора (1 → 3 → 7 →
  14 → 30 дней). В Obsidian с Dataview повторы на сегодня можно вывести так:

  ````markdown
  ```dataview
  TABLE повтор AS "Повтор"
  FROM "Уроки"
  WHERE тип = "урок" AND повтор AND повтор <= date(today)
  SORT повтор ASC
  ```
  ````

Настройки — `~/.claude/tutor.json`, наставник создаёт его сам:

```json
{ "lessons": "C:/Users/me/Obsidian/Уроки" }
```

`"lessons": null` — учиться без записи. Ошибки хуков —
`~/.claude/tutor-state/errors.log`.

Режим «Тема» вырос из системы
[amosblomqvist/learn](https://github.com/amosblomqvist/learn) (видео
«How I Use AI to Learn Things»).

## learned

Записывается не «что я выучил», а **где застрял и до какого уровня поднимал
помощь** — по строке на остановку, с тегом `#пробел/<тема>`.

- `/learned:learned` в конце сессии — наставник предлагает список остановок на
  правку, строку «в чём был переход» пишешь ты сам.
- `/learned:recall` в начале — два-три вопроса по прошлым остановкам и
  подсказка, какие уроки `tutor` пора повторить.
- **Карта пробелов** собирается Dataview-запросом из заметок дня: тема,
  которая попалась три раза, — уже дыра, а не случайность.

Настройки — `~/.claude/learned.json`, навык спросит пути один раз и создаст
карту пробелов сам:

```json
{
  "vault": "C:/Users/me/Obsidian",
  "journal": "Журнал",
  "filename": "DD.MM.YYYY",
  "template": "Шаблоны/Заметка дня",
  "map": "Пробелы — карта.md"
}
```

## incident

Ты — дежурный разработчик: сервис упал в проде, люди вокруг уже выдвинули
версии, а у тебя ограниченное число проверок. `/incident:incident`, «дай
инцидент», «найди баг как дежурный».

- **Всё по-настоящему.** Claude собирает маленький сервис с багом, прод-лог,
  отчёты Sentry и стенд. Проверки — `Открой <файл>`, `Лог`, `Sentry <id>`,
  `Стенд: <вход>`, `Отладка: <print> + <вход>` — исполняют настоящий код,
  каждая стоит одну проверку из бюджета.
- **Подогнать ответ нельзя.** Карта бага запечатана SHA-256 до брифинга:
  хеш ты видишь сразу, в финале печать проверяется, а твой фикс — дословно
  как ты его описал — гоняют скрытые тесты. Любой корректный фикс проходит.
- **Финальный ответ** — причина, фикс, уверенность в %, последствия для
  бизнеса и решение за персонажа («откатывать ли релиз»). Журнал прогнозов
  считает ошибку уверенности (Brier) — видно, научился ли ты знать, что прав.
- **Лестница уровней 1–5**: от исключения с трейсбеком до двух
  взаимодействующих причин под давлением срока. Домены чередуются: веб, CSV,
  CLI, SQL, ML-данные, асинхронность.
- **Для начинающих в Python**: вопросы о языке бесплатны, причину можно
  назвать своими словами, тема языка разбирается после финала.

Нужен Python 3 в `PATH`, только стандартная библиотека. Игры и журнал —
`~/.claude/incidents/`, рабочий проект не трогается.

## web-design

На визуальную задачу (лендинг, экран, форма, дашборд, компонент) собирает **три
отдельных, ощутимо разных варианта** — не один макет в трёх цветах:

- **A. Продуктовый** — выверенная сетка, строгая иерархия (в духе refero).
- **B. Живой** — анимация и интерактивные фоны (в духе reactbits).
- **C. Характерный** — свечения, градиентные бордеры (в духе uiverse).

Выход — папка `design-variants/` с переключателем и тремя файлами вариантов.

## Разработка

```
.claude-plugin/marketplace.json   # каталог плагинов
plugins/<плагин>/
  .claude-plugin/plugin.json      # манифест
  commands/                       # слэш-команды плагина
  skills/<навык>/SKILL.md         # навык (+ references/)
  hooks/                          # хуки (у tutor — запись урока)
```

Тесты хуков: `node --test "plugins/tutor/hooks/*.test.mjs"`.

В `plugin.json` нет поля `version`: каждый коммит — новая версия, и
`/plugin marketplace update` подтягивает последнее состояние.

Новый плагин: `plugins/<плагин>/.claude-plugin/plugin.json` (минимум — `name`),
навык в `skills/<навык>/SKILL.md`, строка в `marketplace.json` и в таблицу выше.
